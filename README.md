## 🌟 프로젝트 개요
- **프로젝트명**: AI 유튜브 검색기 (AI YouTube Searcher)
- **핵심 기술**: Google Gemini API (`gemini-3.5-transcribe`, `gemini-3.8-flash`), Streamlit, YouTube IFrame API, yt-dlp
- **목적**: 유튜브 영상의 음성을 초단위 타임스탬프로 전사하고, 실시간 음성에 맞추어 대본을 동기화하며, Gemini 3.8 AI를 통한 질의응답 및 원클릭 타임스탬프 이동(Seek & Play)을 지원하는 구글 유튜브 스타일 차세대 미디어 웹 서비스

### Q&A 1. 대본-챗봇 카테고리 통합 및 유튜브 스타일 UI 개편

#### 🙋 사용자 질문:
> *"방금 전에 만든 AI 유튜브 검색기에서 실시간 대사 밑에 있는 시간대별 대본을 AI 챗봇과 합쳐서 카테고리를 지정해서 같은 구역에 지정해줘! UI는 깔끔하게 구글 유튜브처럼 만들어줘"*

#### 🤖 AI 어시스턴트 답변 및 구현 내용:
- **구현 계획**:
  - 좌측 비디오 플레이어 하단에 있던 대본 패널을 우측 사이드 패널로 이동
  - 유튜브 웹 다크 테마 디자인(유튜브 레드 `#ff0000`, 배경 `#0f0f0f`, 카드 `#181818`, 둥근 알약 버튼) 적용
  - 우측 구역을 3대 카테고리 탭(`📑 시간대별 대본`, `💬 Gemini AI 챗봇`, `🏷️ 주제별 요약/챕터`)으로 통합
- **세부 개발 작업**:
  1. `qa_engine.py`: `gemini-3.8-flash` 기반의 주제별 챕터 자동 추출 함수 `extract_video_chapters` 신규 추가.
  2. `app.py`:
     - **좌측 메인 미디어 영역**: 16:9 반응형 플레이어, 무중단 볼륨 슬라이더, 실시간 라이브 자막 배너(🔴 Live Captions), 영상 메타데이터 카드 및 대본/오디오 다운로드 버튼 배치.
     - **우측 통합 사이드 패널**:
       - `📑 시간대별 대본`: 대본 실시간 키워드 검색, 타임스탬프 클릭 시 즉시 영상 점프, 현재 대본 하이라이트.
       - `💬 Gemini AI 챗봇`: 원클릭 추천 질문 칩(`핵심 요약`, `결론 정리`, `주요 쟁점`) 및 관련 구간 타임스탬프 연동.
       - `🏷️ 주제별 요약/챕터`: AI가 자동 분류한 챕터별 카드 및 원클릭 이동.

### Q&A 2. 실시간 음성-대본 싱크, 5개 축소 뷰 & 호버 타임라인/썸네일 툴팁

#### 🙋 사용자 질문:
> *"영상이 재생되는 동안 나오는 음성에 실시간으로 맞춰서 시간대별 대본이 표시되면 좋겠고 나오게 되는 대본은 화면에서 5개정도로 축소해주고 드래그 하면서 전체를 볼 수 있게 만들어줘. 그리고 영상에 마우스를 가져다대면 유튜브 영상처럼 타임라인과 썸네일 시간대가 분초 단위로 표시되게 해줘."*

#### 🤖 AI 어시스턴트 답변 및 구현 내용:
- **핵심 요구사항 3가지 완벽 구현**:
  1. **⚡ 실시간 음성-대본 0ms 싱크**:
     - 기존 분리형 IFrame 방식의 브라우저 샌드박스 통신 지연 문제를 해결하기 위해 **단일 통합 JavaScript 실행 컨텍스트**로 전면 재설계.
     - 150ms마다 `player.getCurrentTime()`을 측정하여 실제 음성과 정확히 일치하는 대본 카드를 실시간 파란색 하이라이트(`active` 상태)로 표시.
     - 영상 재생에 따라 현재 대본이 뷰포트 내 중앙에 항상 보이도록 부드럽게 자동 추적 스크롤(`scrollIntoView`) 적용.
  2. **📑 대본 5개 단위 컴팩트 뷰 & 자유 드래그/스크롤**:
     - 대본 목록의 높이를 화면에서 **정확히 5개 카드가 보이는 높이(약 235px)**로 최적화.
     - 마우스 휠, 스크롤바 드래그, 터치로 영상 전체 대본을 자유롭게 위아래로 탐색 지원.
     - 사용자가 직접 스크롤/드래그 중일 때는 2.5초간 자동 스크롤을 일시 대기하여 편안한 대본 열람 보장.
  3. **🎞️ 유튜브 정통 인터랙티브 타임라인 & 썸네일/분초 호버 툴팁**:
     - 16:9 비디오 플레이어 바로 아래에 유튜브 공식 프로그레스 바(빨간색 재생 바, 회색 버퍼 바, 마우스 위치 프리뷰 바, 붉은색 스크러버 노브) 배치.
     - 마우스를 올리면(Hover) 커서를 따라 **실제 영상 썸네일 미리보기(`mqdefault.jpg`)**와 **분:초 단위 시간대(`MM:SS`, 예: 01:24)** 플로팅 툴팁이 실시간으로 따라다님.
     - 타임라인 클릭 시 해당 시간대로 비디오가 즉시 이동(`player.seekTo`).

### Q&A 4. 상단 중앙 알약 검색창 개편, 대본 5개 컴팩트 뷰 & 스마트 키워드 클라우드, UI/UX 고도화

#### 🙋 사용자 질문:
> *"리드미 파일을 읽고 내가 설계하려고 했던 내용들을 찾고 의도를 파악해서 적용시켜주고 보완하면 좋을 것들 적용시키고 ui ux 고도화 시켜 그리고 링크 검색창을 위로 빼두고 가운데 정렬시키도록해"*

#### 🤖 AI 어시스턴트 답변 및 구현 내용:
- **1. 상단 링크 검색창 최상단 배치 및 완벽한 중앙 정렬**:
  - 기존 100% 가로 폭 전개 방식에서 유튜브 웹 공식 스타일의 **상단 헤더 3열 중앙 정렬(Center-aligned)**로 전면 개편.
  - 좌측: 유튜브 AI Studio 로고 + Gemini 뱃지
  - 중앙: 둥근 알약형 검색 인풋(`border-radius: 20px 0 0 20px`) + 돋보기 검색 버튼(`border-radius: 0 20px 20px 0`)
  - 우측: 실시간 싱크 & 무중단 AI 상태 칩
- **2. 대본 5개 단위 컴팩트 뷰포트 & 중앙 추적 스크롤 복원**:
  - Q&A 2 설계 의도에 맞추어 대본 뷰포트를 정확히 5개 항목 높이(`236px`)로 최적화.
  - 영상 재생에 따라 현재 대본이 5개 중 정중앙 3번째 카드(`block: 'center'`)에 위치하도록 부드러운 자동 추적 적용.
  - 마우스 휠 및 드래그 스크롤 시 2.5초 디바운싱 대기로 사용자 자유 탐색 보장.
- **3. 패널 공간 최적화: 스마트 인사이트 & 키워드 클라우드 위젯**:
  - 5개 대본 하단 빈 공간에 실시간 발화 통계(총 발화 개수, 현재 뷰 모드) 배치.
  - 대본 텍스트로부터 핵심 명사 키워드를 자동 추출하여 인터랙티브 `#태그 칩` 클라우드 렌더링.
  - 키워드 칩 클릭 시 해당 단어로 대본 실시간 즉시 필터링.
  - `[ ↕️ 전체 뷰 / 🔍 5개 컴팩트 ]` 원클릭 뷰 토글 버튼 지원.
- **4. 미디어 플레이어 & 자막 컨트롤 고도화**:
  - 원클릭 음소거(Mute) 토글 및 볼륨 연동 슬라이더.
  - 5초 전/후 퀵 스킵 버튼(`⏪ -5s`, `+5s ⏩`) 및 배속 조절 드롭다운(`0.75x`, `1.0x`, `1.25x`, `1.5x`, `2.0x`).
  - 실시간 라이브 자막 배너에 현재 발화 문장 원클릭 클립보드 복사(`📋 복사`) 버튼 추가.
- **5. Gemini 3.8 Flash AI 챗봇 및 챕터 기능 강화**:
  - 추천 질문 칩 5종(`📌 3줄 핵심 요약`, `🎯 최종 결론`, `🔍 주요 원인 분석`, `💡 핵심 키워드 정리`, `❓ Q&A 팩트체크`) 확장.
  - AI 답변 원클릭 복사 버튼 및 타임스탬프 원클릭 점프 칩 제공.
  - 현재 재생 시간대에 맞추어 우측 챕터 카드 실시간 하이라이트 표시.

## 🛠️ 주요 기술 아키텍처 및 해결 과제

| 해결 과제 | 문제점 | 해결 방법 |
| :--- | :--- | :--- |
| **IFrame 통신 지연/차단** | 분리된 Streamlit 컴포넌트 간 `postMessage` 이벤트가 브라우저 보안 격리로 인해 전달되지 않음 | 플레이어와 우측 탭 패널을 **단일 통합 HTML 컴포넌트**로 묶어 동일 window 컨텍스트에서 0ms 즉각 반응하도록 구현 |
| **실시간 음성-대본 싱크** | 재생 시간과 대본 타임스탬프 간 오차 발생 | 150ms 고속 폴링 타이머 및 `start ~ end + 0.35s` 정밀 구간 매핑 알고리즘 적용 |
| **대본 가시성 및 사용자 경험** | 대본 목록이 너무 길어 화면을 과도하게 차지 | 뷰포트를 **정확히 5개 항목(235px)**으로 제한하고, 자동 추적 스크롤과 사용자 드래그 스크롤 간섭 방지(Debouncing) 적용 |
| **유튜브 호버 툴팁 구현** | 마우스 위치에 따른 동적 시간 계산 및 이미지 렌더링 필요 | 타임라인 컨테이너의 상대 x좌표 비율(`ratio`)을 기반으로 `ratio * duration` 초를 계산하고 `img.youtube.com/vi/{v_id}/mqdefault.jpg`와 `MM:SS` 포맷 툴팁을 플로팅 배치 |
| **무중단 챗봇 응답** | Streamlit 폼 제출 시 페이지가 리로드되어 영상 재생이 끊김 | 클라이언트 사이드에서 Google Generative Language REST API (`gemini-3.8-flash`)를 비동기 `fetch` 호출하여 영상 재생 중단 없이 실시간 응답 렌더링 |

## 🚀 빠른 실행 방법

### 1. 가상환경 및 패키지 확인
```powershell
pip install -r e:\GoogleAiStudio-Tutorial\ai-youtube-searcher\requirements.txt
```

### 2. Streamlit 웹 애플리케이션 실행
```powershell
streamlit run e:\GoogleAiStudio-Tutorial\ai-youtube-searcher\app.py
```
*(웹 브라우저에서 `http://localhost:8501` 접속)*

### 3. 사용 요령
1. **상단 검색창**: 유튜브 영상 URL 입력 후 `[🔍 검색 및 분석]` 클릭
2. **좌측 영상 재생**: 마우스를 타임라인에 올려 **썸네일 및 분초 확인**, 원하는 위치 클릭으로 점프
3. **우측 탭 탐색**:
