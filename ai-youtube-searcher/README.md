# AI 유튜브 검색기 (AI YouTube Searcher) 🔍🎬

유튜브 영상 URL을 입력하면 실시간으로 영상을 로드하고, **Gemini 3.5 Flash Transcribe**를 통해 오디오에서 세부 타임스탬프와 대본을 추출하며, **Gemini 3.8 Flash**를 활용하여 영상 질의응답 및 **주제별 챕터 요약, 대본 타임스탬프 원클릭 점프(Seek & Play)**를 제공하는 구글 유튜브 스타일 차세대 AI 미디어 웹 애플리케이션입니다.

---

## 🌟 핵심 기능 및 UI 특징

1. **구글 유튜브(YouTube) 공식 다크 테마 디자인**:
   - 세련된 `#0f0f0f` 다크 배경과 유튜브 알약 검색창, 탭 필터 칩스 UI
2. **좌측 메인 미디어 영역**:
   - **16:9 반응형 플레이어**: 잘림 없는 완벽한 비율과 고화질 재생
   - **무중단 볼륨 슬라이더**: 페이지 새로고침 없이 0~100% 음향 조절 및 실시간 재생 시간 표시
   - **실시간 라이브 자막 (Live Captions)**: 현재 발화 중인 대사가 빨간색 펄스 배너에 실시간으로 출력
   - **영상 상세 정보 & 다운로드 바**: 채널명, 조회수, `대본.txt`, `오디오.m4a` 원클릭 다운로드
3. **우측 통합 사이드 패널 (카테고리 탭)**:
   - **📑 시간대별 대본 (Transcript)**:
     - 대본 내 실시간 키워드 검색
     - 타임스탬프 칩 클릭 시 좌측 플레이어 해당 구간으로 즉시 이동
     - 영상 재생 위치에 맞춰 현재 대본 카드 자동 하이라이트 & 자동 스크롤
   - **💬 Gemini AI 챗봇 (AI Chatbot)**:
     - Gemini 3.8 Flash 기반 초고속 대본 질의응답
     - 원클릭 추천 질문 칩 (핵심 요약, 결론 정리, 주요 쟁점)
     - 연관 영상 타임스탬프 칩 제공
   - **🏷️ 주제별 요약/챕터 (Key Chapters)**:
     - Gemini 3.8 Flash가 대본을 분석하여 영상의 주요 챕터 및 카테고리별 요약 카드 생성
     - 챕터 카드 클릭 시 해당 시작 시간으로 즉시 이동

## 💡 사용 시나리오

1. **상단 검색창에 유튜브 영상 링크 입력**:
   - 예: `https://www.youtube.com/watch?v=...` 입력 후 **[🔍 검색 및 분석]** 클릭
2. **자동 분석 진행**:
   - `gemini-3.5-transcribe`가 타임스탬프 대본을 생성하고, `gemini-3.8-flash`가 주제별 챕터를 자동 추출
3. **좌측 영상 재생 및 실시간 자막 확인**:
   - 영상이 재생되면서 하단 빨간색 라이브 자막 배너에 현재 대사가 실시간으로 표시
4. **우측 카테고리 탭 탐색**:
   - **[📑 시간대별 대본]**: 원하는 대본을 클릭하여 영상 특정 구간으로 점프
   - **[💬 Gemini AI 챗봇]**: 영상 내용 질문 또는 추천 칩 클릭으로 빠른 답변 확인
   - **[🏷️ 주제별 요약/챕터]**: 영상의 전체 흐름과 주제별 핵심 요약 확인 및 원클릭 이동
